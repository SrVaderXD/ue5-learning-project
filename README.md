# UE5 Learning Project

This repository contains a small Unreal Engine 5 project created for learning
and experimentation purposes.

The project follows an online course and focuses on understanding core UE5.

## Engine Version

- Unreal Engine 5.6

## Notes

This repository is part of an ongoing learning process and will be expanded
incrementally.

## Implemented so far

- Enhanced Input System
- Character movement using the camera forward vector
- Animation state handling using a C++ enum
- Foot Inverse Kinematics (IK)
- Collision and overlap handling
